# Code map – backend modules

Part of `docs/CODEMAP.md`; read when you change `shelly_firmware_manager/app/*.py`.

**Modules (`shelly_firmware_manager/app/`)**

|---|---|---|

| `app_options.py` | option validation, merge, log diff | `with_defaults`, `merge`, `change_list`, `download_host_problem`, `download_base_problem`, `LEGACY_DOWNLOAD_BASE` |

| `credentials.py` | per-device passwords (0600; Gen2 HA1 only) | `Credentials.auth_for/candidate/store/remove` (`_save`: fsync; a write error raises `ShellyError`) |
| `changelog.py` | changelog pages → plain text (parsed in a worker thread), last page per generation | `Changelogs.refresh/version_entry/between`, `marked`, `parse` |
| `store_transfer.py` | store export / import files (pure functions, run in a worker thread): ZIP layout `Gen2+\|Gen1/<type>/<file>`, `manifest.json` sealed with HMAC-SHA256 (key: scrypt of the export password), `SHA256SUMS.txt`; every entry and file checked; re-packed archives accepted | `build_export`, `read_export`, `check_directory` (size of the ZIP entry list before `zipfile` reads it, `MAX_DIRECTORY`; ZIP64 refused), `extract_entry`, `generate_password`, `normalize_password`, `derive_key`, `archive_path`, `TransferError` (= ValueError), `FORMAT`, `SCRYPT`, `MAX_MANIFEST`, `MAX_ENTRIES` |
| `backup_store.py` | backups of device settings as files (no device or network access): `<id>.sfmb` = `MAGIC`, header (JSON), zlib payload encrypted with a SHAKE-256 key stream, HMAC-SHA256 tag (encrypt-then-MAC, standard library only); stored files use the key of the app (`key`, 0600), downloaded and exported ones a key from their password (scrypt, `SCRYPT`); a file is decrypted only after its tag was verified | `BackupStore` (`entries`, `of` (by MAC), `get`, `add`, `load`, `delete`, `set_kept`, `prune` (kept ones never count), `sealed_copy`, `known`, `totals`, `warning` (lost key, unreadable files); index rebuilt from the files), `seal`, `open_sealed`, `read_header`, `password_salt`, `derive_key`, `clean_meta`, `normalize_mac`, `BackupError` (= ValueError), `REASONS`, `ID_RE`, `EXTENSION`, `MAX_FILE`, `MAX_PAYLOAD` |
| `shelly_backup.py` | device side of a backup: `read` (Gen2+: `Shelly.GetConfig`, scripts with code, schedules, webhooks; Gen1: `/settings`, `/settings/actions`; secrets `SECRET_KEYS` and the Bluetooth proxy script of Home Assistant left out), `compare` (rows per part, `public_rows`), `restore` (chosen parts made equal to the backup, the device read again: applied only what it then reports; restart when a part asks for it); `digest` and `summary` are pure | `Target` (`rpc`, `get` over `shelly.device_rpc` / `device_get`), `PART_*`, `GEN2_PARTS`, `GEN1_PARTS`, `STEP_RESTART`, `STEP_VERIFY`, `GEN2_NETWORK`, `GEN2_FIXED`, `GEN1_FIXED`, `GEN1_STATE`, `GEN1_CHANNELS`, `PUT_CHUNK`, `MAX_SCRIPT`, `RESTART_*` |
| `tls.py` | certificate pinning for `*.shelly.cloud` | `CertificatePins.ssl_for`, `explain_tls_error` |

### The manager

One object, built from layers: each module holds one class that extends the class of
the layer before, so a layer only uses what lies below it. Everything outside uses
`manager.Manager` only. Module constants live where they are used (tests patch them
there, e.g. `manager_installs.INSTALL_WAIT_S`).
