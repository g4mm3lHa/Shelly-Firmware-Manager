# Code map – backend modules

Part of `docs/CODEMAP.md`; read when you change `shelly_firmware_manager/app/*.py`.

**Modules (`shelly_firmware_manager/app/`)**

| Module | Responsibility | Key names |
|---|---|---|
| `main.py` | start, servers, scheduler loop, clean stop | `main`, `run_schedule`, `start_site`, `VERSION` (= config.yaml) |
| `manager*.py` | all workflows and the state: one object in six layers | see "The manager" below |
| `data_paths.py` | paths below `/data` – always read as `data_paths.NAME` (tests and the demo redirect them) | `DATA_DIR`, `STATE_FILE`, `FW_DIR`, `CREDENTIALS_FILE`, `CHANGELOG_FILE`, `EVENTS_FILE` |
| `shelly.py` | device and manufacturer access, auth, SSRF/redirect/size guards | `device_info`, `read_settings` (incl. `debug_ws`, `battery` via `_battery_status`), `write_settings`, `validate_settings`, `set_protection`, `protection_status`, `restart`, `trigger_update`, `OtaChannel`, `fetch_offer` (Gen2+; with the installed version: header `Shelly-Info` {app, ver} → next step, `steps`), `url_sha256` (SHA-256 named by a download URL, checked by `download_firmware`), `fetch_gen1_offers` / `gen1_offer` (one list for all Gen1 types), `download_firmware`, `fetch_cloud_text`, `_cloud_get`, `check_download_url`, `resolve_device_origin`, `DeviceAuth`, `parse_version`, `clip`, `error_text` |
| `web_ui.py` | Ingress UI + JSON API, CSRF/JSON/size middleware | `build_ui_app` (all handlers inside), `security`, `guarded`, `SECURITY_HEADERS` |
| `download_server.py` | GET/HEAD `<sha256>.<ext>` for the Shellys; warnings for rejected requests limited per client and 10 min | `build_download_app`, `strip_server_header`, `RejectLog` (`REJECT_WINDOW_S`, `REJECT_MAX_CLIENTS`) |
| `schedule.py` | every N days at HH:MM, HA time zone, DST, catch-up | `configure`, `status`, `seconds_until`, `next_run`, `local_zone` |
| `app_options.py` | option validation, merge, log diff | `with_defaults`, `merge`, `change_list`, `LEGACY_DOWNLOAD_BASE` |
| `events.py` | activity log (JSON Lines), severity, entry IDs, delete/clear | `EventLog.add/list/remove/clear`, `worst`, `user_from`, `KINDS`, `ENTRY_ID_RE` |
| `credentials.py` | per-device passwords (0600; Gen2 HA1 only) | `Credentials.auth_for/candidate/store/remove` |
| `changelog.py` | changelog pages → plain text (parsed in a worker thread), last page per generation | `Changelogs.refresh/version_entry/between`, `marked`, `parse` |
| `store_transfer.py` | store export / import files (pure functions, run in a worker thread): ZIP layout `Gen2+\|Gen1/<type>/<file>`, `manifest.json` sealed with HMAC-SHA256 (key: scrypt of the export password), `SHA256SUMS.txt`; every entry and file checked; re-packed archives accepted | `build_export`, `read_export`, `extract_entry`, `generate_password`, `normalize_password`, `derive_key`, `archive_path`, `TransferError` (= ValueError), `FORMAT`, `SCRYPT`, `MAX_MANIFEST`, `MAX_ENTRIES` |
| `tls.py` | certificate pinning for `*.shelly.cloud` | `CertificatePins.ssl_for`, `explain_tls_error` |

### The manager

One object, built from layers: each module holds one class that extends the class of
the layer before, so a layer only uses what lies below it. Everything outside uses
`manager.Manager` only. Module constants live where they are used (tests patch them
there, e.g. `manager_installs.INSTALL_WAIT_S`).

| Layer / module | Class | Content |
|---|---|---|
| 1 `manager_core.py` | `ManagerCore` | state and `__init__` (options incl. `allow_downgrade`, missing = off); persistence `_load`, `save` (atomic), `_remove_partial_downloads`; Home Assistant `_registry`, `notify`, `_supervisor_post`, `app_page` (changelog link: slug from `/addons/self/info`, cached in `app_slug`); options `options_view`, `save_options`, `restart_app`, `download_base_issue`, `confirm_download_base`; check slots `checking` (full check only), `device_checks` (single checks: id → queued/running), `reserve_check` (synchronous; "all" exclusive, "device" refused for the full check and for a device being checked, installed or reloaded), `_reserved`, `busy`, `_progress`, `_end_check`, `_end_device_check`, `_release_check_state` (shared caches end with the last check); credentials `_auth`, `_auth_for`. Constants: `STATUS_*`, `ACTIVITY_*`, `SOURCE_*`, `DOWNLOAD_BASE_MESSAGES`, `severity_of`; `PENDING`, `holds_file` (ready, installing, failed installation to retry or `store_fallback`, also while asleep); runtime `_scan_user` / `_check_users` (user of the full / single checks and their downloads), `_header_check`, `_header_got`, `_step_checks`; store transfer `import_max` (bytes of `import_max_mb`), `_export`, `_import`, `_import_lock`; first start `first_start_open` (no state.json at start = fresh installation; `reserve_check` raises `FIRST_START_BLOCK` while open), `first_start_notified` |
| 2 `manager_store.py` | `FirmwareStore` | `_register_firmware`, `cleanup_firmware` (housekeeping only), `_intact` (SHA-256 verified once per file and check), `_stored_firmware` (exactly the offered version; uploads too for Gen2+), `_store_offer` (next higher stored version, downloads and uploads: Gen1 store first, Gen2+ store fallback), `firmware_list`, `firmware_changelog`, `store_size`, `delete_firmware` (`_delete_lock`: all files during the full check, files of a checked device's type during a single check, a file being installed; `_release_file`: holding devices lose the provision, log `released`), `free_space` (free bytes of the store volume, None if unreadable; Firmware tab); downgrade `downgrade_versions/match/blocker` (`DOWNGRADE_OFF` while `allow_downgrade` is off), `_downgrade_candidates`, `_downgrade_count`; transfers in parts `_receive_part` (`PART_MAX` 8 MiB per request – Ingress refuses bodies above 16 MiB; first part starts a transfer, further parts name it and continue at the received size; `PART_TTL_S`; one incomplete transfer per kind in `_receiving`); upload `stage_upload_part` (`stage_upload` = one part) → `confirm_upload` / `cancel_upload`, `_read_manifest`, `_sha256_of`, `upload_types`; store export `prepare_export` (password once, key in memory, `EXPORT_TTL_S`) → `build_export` (single-use token, temporary `EXPORT_PREFIX` file, log `export`); store import `stage_import_part` (`stage_import` = one part; ≤ `import_max`, free space `SPACE_MARGIN`) → `check_import` (`_classify`: new / same / conflict, `_merge_note`) → `confirm_import` (refused during checks; `.part-` + rename; merges missing data; answers the first-start question; log `import`) / `cancel_import`; `skip_first_start` (log `setup`), `announce_first_start` (one HA notification) |
| 3 `manager_devices.py` | `DeviceSettings` | `_apply_info`, `_read_settings`, `_settings_device` (guards), `refresh_settings`, `reload_device`, `set_ignored`, `change_settings` (read-back, `_not_applied` → warning and failed log entry), `restart_device`, `set_device_password` → `_password_action` (verify on the device; `keep=False`: enable/change without storing, a stored password is removed after the device confirmed); several devices `set_passwords` (`BULK_MODES` store/set, `bulk_password_step`: set → enable or change, skipped with a reason; parallel up to `max_parallel_installs`, each device through `set_device_password`) |
| 4 `manager_checks.py` | `Checks` | `scan` (full check under `lock`; scheduled and not startable → `_skip_scheduled`: logged, not repeated) / `check_device` (no lock: parallel to other devices; `SCHEDULE_USER`) → `_scan_all` → `_check_entries` (TaskGroup, `CHECK_PARALLEL`) → `_check_entry` (a known battery device that does not answer: `STATUS_ASLEEP`, `ASLEEP_MESSAGE`, `_unreachable`) → `_scan_device`: Gen1 store first (`_store_offer`, `_provide_stored`), else `_manufacturer_offer` (one list: `GEN1_OFFERS`); Gen2+ `_step_offer` (shared request per firmware ID and installed version; `_newest_version` → `step_target` for intermediate versions; server error → `_store_fallback`: `store_fallback` + `STORE_FALLBACK_HINT`), reference request `_start_header_check` / `_finish_header_check` (shared by running checks; returns the ignored flag for `_log_check`; `HEADER_CHECK`, `HEADER_WARNING`); `_provide` per (type, version) (single flight shared by the full check and all single-device checks: `_provisions`; waiting devices in `_provision_waiters` all show `downloading` while `_fetching`) → `_stored_firmware` or `shelly.download_firmware`; `_offer_source`, `OFFER_*` (source of the provided update); `_log_check` (`ignored`: names of the ignored devices of a full check, counted in `result`, no finding), `_store_changelogs` / `_attach_changelogs`, `changelog_for`, `_notify_new_updates`, `scan_due_in` |
| 5 `manager_installs.py` | `Installs` | `approval_matches`, `install` → `_install_approved` (slots, log) → `_install` (pre-check, WebSocket `_update_over_websocket` or HTTP `trigger_update`) → `_await_target_version`: OTA events `_await_over_events` (`OTA_*` timings: stall, restart, boot; `ota_phase` "restarting"; `_wait_ota`, `_poll_version`, `_confirm`) or `_await_by_polling` (`INSTALL_*` timings, 5 min; also when the WebSocket ends before applied); `_ota_error_text`: rejected after a download or not reachable, failed installation → `install_failed` (retry via `approval_matches`; also for `store_fallback`, entry flag `unverified`), `_after_downgrade`; confirmed intermediate version → `_step_checks` → `_check_step` at once (`check_device(trigger="step")`, otherwise no check follows an installation); refused while the device itself is checked; download server support `may_download`, `record_download`, `_downloaded`, `_reset_download`, `_install_diagnosis` |
| 6 `manager.py` | `Manager` | `public_state` (only listed fields; per device `downgrades`; `allow_downgrade`, `first_start_open`, `import_max_mb`) |
