# Code map – UI modules

Part of `docs/CODEMAP.md`; read when you change `ui-src/`.

**UI (`ui-src/js/*.js`, `ui-src/style.css` in the repository root → built into `shelly_firmware_manager/app/static/`)**

Single page, `textContent` only. Polls `api/state` (30 s idle, 3 s busy, paused when
hidden, ETag). ES modules, bundled by `tools/build_ui.py` (esbuild, entry `main.js`)
into the one classic script `app/static/app.js`; never edit `app/static/app.js|style.css`
by hand. The dictionaries are not part of `app.js`: the loader `ui-src/start.js` (the only
script of `index.html`, built into `static/start.js`) picks the language (`lang.js`), then
adds `static/i18n-<code>.js` (classic script, global `SFM_TEXTS`; none for English) and
`static/app.js` in this order, with its own version query. A module exports only what another module imports. `ui-src/style.css` starts with the
design tokens (`:root`: font sizes, radii, lines, tinted surfaces `--surf`/`--surf-hi` (weaker under `data-scheme=light`; every surface tint mixes `--tint`: the text colour for the base colour Default, else the primary colour), base colours `--base-*` (`data-base-color` of the root element replaces `--primary-color` with `!important` against the inline theme copy), coloured text, control height, monospace font, shadows,
layers, icon sizes, beta colour), then base, building blocks (tone system `--tone`, rows, tiles, dialog
tables, `.icon-text`), page head and one section per tab (`docs/ui/common.md`); new styles use them.
